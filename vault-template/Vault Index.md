## About me

Replace this section with a short profile, or ask Claude to interview you and write it
(prompt 2 in the starter kit's setup prompts). Cover who you are, what you do for work, the projects you
juggle, the people who come up often, and how you like to be spoken to. Keep it to one
screen: the SessionStart hook injects this file into every session, so its length is a
per-session cost.

## Map

Each folder carries its own index note, named after the folder, listing every note in it with
a one-line description. Go folder index first, then the one or two notes you actually need.
Never bulk-read the vault.

- **[[Projects]]** - one note per project, client or ongoing piece of work.
- **[[People]]** - one note per person who comes up often.
- **[[Jobs]]** - priming notes, one per recurring task. Read the matching one BEFORE doing the
  job. Each opens with a "Read first" list naming the notes that job needs.
- **Inbox/** - quick captures not yet filed. Empty is the goal state.
- **Journal/** - the day log. One note per day, filename is the date, built from
  `Daily note template.md`. The only record of work that produced no durable fact, dead ends
  and rejected options included, so check it before re-attempting something that looks
  untried. Governed by [[Daily note]].
- **[[Archive]]** - finished and abandoned notes. History, not state. Never archive on your own
  initiative.
